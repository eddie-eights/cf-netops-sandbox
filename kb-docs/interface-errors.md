# インターフェイスのエラーカウンタが増えるとき

## 見分け方

`show interfaces GigabitEthernet0/1` の次のカウンタが増え続けている。

| カウンタ | 疑うもの |
|---|---|
| `CRC` | ケーブル・SFP の劣化、コネクタの汚れ |
| `input errors` | CRC を含む受信エラーの合計 |
| `runts` / `giants` | MTU の不一致、デュプレックスの不一致 |
| `output drops` | 帯域の不足、キューの溢れ |

## 一次対応

1. `clear counters GigabitEthernet0/1` でカウンタを 0 にし、5 分後にもう一度見る。増えていなければ過去のエラー。
2. 両端のスピードとデュプレックスが一致しているか確かめる。片側だけ `auto` は `late collision` の原因になる。
3. CRC が増え続けるなら、ケーブルを交換する。次に SFP を交換する。
4. `output drops` だけが増えるなら、物理ではなく帯域の問題。トラフィックのグラフを見る。

## 記録

交換した部材と時刻は変更記録に残す。
