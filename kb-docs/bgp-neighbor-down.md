# BGP ネイバーがダウンしたとき

## 見分け方

- ログに `%BGP-5-ADJCHANGE: neighbor 192.0.2.1 Down` が出る。
- `show ip bgp summary` で、該当ネイバーの State/PfxRcd 欄が数字ではなく `Idle` や `Active` になっている。

## 一次対応

1. 対向との疎通を確かめる。`ping 192.0.2.1 source Loopback0`。
2. 物理リンクを確かめる。`show interfaces` で該当インターフェイスが `up/up` か。
3. 設定の変更履歴を確かめる。直近の変更で AS 番号やパスワード（MD5 認証）を変えていないか。
4. `%TCP-6-BADAUTH` が出ていれば、認証パスワードの不一致を疑う。
5. ホールドタイマーの満了（`hold time expired`）が理由なら、回線の輻輳か CPU 高負荷を疑う。

## やってはいけないこと

- 原因が分からないまま `clear ip bgp *` を打たない。全ネイバーが張り直しになり、影響が広がる。
  張り直すなら `clear ip bgp 192.0.2.1 soft` で対象を絞る。

## エスカレーション

30 分以内に復旧しない場合は、ネットワーク運用チームの当番に連絡する。
